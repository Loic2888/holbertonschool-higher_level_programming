# Python - if/else, loops, functions

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)

## Description

This directory introduces fundamental control flow mechanisms in Python. It covers `if`, `elif`, `else` statements, `while` and `for` loops, and the definition and usage of basic functions.

## Files

| File | Description |
| :--- | :--- |
| `0-positive_or_negative.py` | Assigns a random signed number to a variable and prints whether it is positive, negative, or zero. |
| `1-last_digit.py` | Prints the last digit of a randomly generated number and evaluates its magnitude. |
| `2-print_alphabet.py` | Prints the ASCII alphabet in lowercase, without a newline. |
| `3-print_alphabt.py` | Prints the ASCII alphabet in lowercase, excluding 'q' and 'e'. |
| `4-print_hexa.py` | Prints all numbers from 0 to 98 in decimal and hexadecimal notations. |
| `5-print_comb2.py` | Prints numbers from 00 to 99, formatted with leading zeros. |
| `6-print_comb3.py` | Prints all possible different combinations of two digits. |
| `7-islower.py` | Contains a function `islower(c)` that checks for a lowercase character. |
| `8-uppercase.py` | Contains a function `uppercase(str)` that prints a string in uppercase. |
| `9-print_last_digit.py` | Contains a function `print_last_digit(number)` that prints and returns the last digit of a number. |
| `10-add.py` | Contains a function `add(a, b)` that adds two integers. |
| `11-pow.py` | Contains a function `pow(a, b)` that computes `a` to the power of `b`. |
| `12-fizzbuzz.py` | Contains a function `fizzbuzz()` that prints numbers from 1 to 100 adhering to the FizzBuzz rules. |
