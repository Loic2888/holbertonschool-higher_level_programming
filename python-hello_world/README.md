# Python - Hello, World

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)

## Description

This directory contains introductory exercises to Python programming. The focus is on basic syntax, variables, string manipulation, formatting, and using the `print()` function effectively.

## Files

| File | Description |
| :--- | :--- |
| `2-print.py` | A script that prints a specific string followed by a new line. |
| `3-print_number.py` | A script that prints an integer followed by "Battery street". |
| `4-print_float.py` | A script that prints a float with a precision of 2 digits. |
| `5-print_string.py` | A script that prints a string 3 times, followed by its first 9 characters. |
| `6-concat.py` | A script that concatenates two strings to form a specific welcome message. |
| `7-edges.py` | A script that demonstrates string slicing (first 3 letters, last 2 letters, middle word). |
| `8-concat_edges.py` | An advanced string slicing exercise to extract a specific sentence from a long text. |
| `9-easter_egg.py` | A script that prints "The Zen of Python", by Tim Peters. |
