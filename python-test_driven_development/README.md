# Python - Test-Driven Development (TDD)

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)

## Description

This directory delves into the practice of **Test-Driven Development (TDD)** in Python. It covers writing comprehensive unit tests using the `unittest` module, as well as utilizing `Docstrings` for inline documentation and testing.

## Files

| File | Description |
| :--- | :--- |
| `0-add_integer.py` | A function that adds two integers, accompanied by robust type-checking and tests. |
| `2-matrix_divided.py` | A function that divides all elements of a matrix by a divisor, handling division by zero and type errors. |
| `3-say_my_name.py` | A function that prints `My name is <first name> <last name>`. |
| `4-print_square.py` | A function that prints a square using the character `#`, validating the size input. |
| `5-text_indentation.py` | A function that prints text with 2 new lines after these characters: `.`, `?`, and `:`. |
| `6-max_integer.py` | A module and tests for finding the maximum integer in a list of integers. |
| `tests/` | A subdirectory containing the corresponding `unittest` files for the functions above. |
