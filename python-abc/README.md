# Python - Abstract Base Classes (ABC)

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)

## Description

This directory focuses on defining and utilizing **Abstract Base Classes (ABCs)** and interfaces in Python. It introduces concepts like Duck Typing, iterators, and multiple inheritance patterns.

## Files

| File | Description |
| :--- | :--- |
| `task_00_abc.py` | Introduction to the `abc` module and defining abstract methods. |
| `task_01_duck_typing.py` | Exploring "Duck Typing" concepts, where object suitability is determined by the presence of certain methods rather than the object's type. |
| `task_02_verboselist.py` | Creating a list subclass (`VerboseList`) that prints notifications upon modification. |
| `task_03_countediterator.py` | Implementing a custom iterator that keeps a count of how many items have been yielded. |
| `task_04_flyingfish.py` | A study of multiple inheritance, defining a `FlyingFish` class that inherits from both a `Bird` and a `Fish`. |
| `task_05_dragon.py` | Further exploration of mixins and multiple class inheritance topologies. |
