# Python - Import Modules

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)

## Description

This directory explores how to import code from other files, use Python's built-in modules, and handle command-line arguments using `sys.argv`.

## Files

| File | Description |
| :--- | :--- |
| `0-add.py` | Imports an `add` function from a hidden file and prints the result of `1 + 2`. |
| `1-calculation.py` | Imports math functions (`add`, `sub`, `mul`, `div`) and performs operations on variables. |
| `2-args.py` | A script that prints the number of and the list of its command-line arguments. |
| `3-infinite_add.py` | A script that prints the sum of all numerical command-line arguments. |
| `5-variable_load.py` | Imports a variable `a` from `variable_load_5.py` and prints its value. |
