# Python - Exceptions

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)

## Description

This directory introduces the concept of **Exceptions** in Python. It covers error handling using `try`, `except`, `else`, and `finally` blocks, as well as raising standard and custom exceptions.

## Files

| File | Description |
| :--- | :--- |
| `0-safe_print_list.py` | Prints `x` elements of a list, safely handling `IndexError` exceptions. |
| `1-safe_print_integer.py` | Safely prints an integer utilizing `"{:d}".format()`, catching `ValueError` or `TypeError`. |
| `2-safe_print_list_integers.py` | Prints the first `x` elements of a list and only prints integers, skipping other types. |
| `3-safe_print_division.py` | Divides two integers and prints the result inside a `finally` block. |
| `4-list_division.py` | Divides element by element between two lists, handling division by zero, wrong types, and out of range errors. |
| `5-raise_exception.py` | A function that purposefully raises a `TypeError` exception. |
| `6-raise_exception_msg.py` | A function that raises a `NameError` exception with a specific error message. |
