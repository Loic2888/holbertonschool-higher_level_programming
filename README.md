## Description

This repository contains educational projects and exercises focused on **Higher-Level Programming** concepts, completed during the software engineering program at Holberton School. 

The primary languages used in this repository are **Python** (covering syntax, data structures, Object-Oriented Programming, and API interactions) and **SQL** (covering database design, querying, and Object Relational Mapping).

---

## Repository Contents

The repository is structured into specific projects, each covering a distinct technical topic:

| Directory | Core Concepts Covered |
| :--- | :--- |
| **`python-hello_world`** | Basic Python syntax, variables, printing formatting, and string manipulation. |
| **`python-if_else_loops_functions`** | Control flow statements, loops, and basic function definitions. |
| **`python-import_modules`** | Importing python files, using built-in modules, and processing `sys.argv`. |
| **`python-data_structures`** | Working with Lists and Tuples, and understanding built-in methods. |
| **`python-more_data_structures`** | Working with Sets, Dictionaries, and utilizing `lambda`, `map`, and `filter`. |
| **`python-exceptions`** | Designing robust applications using error handling (`try`, `except`, `finally`). |
| **`python-classes`** | Introduction to Object-Oriented Programming (OOP), objects, classes, and attributes. |
| **`python-more_classes`** | Deeper dive into OOP, class properties, getters/setters, methods, and built-in hooks (`__str__`, `__repr__`). |
| **`python-inheritance`** | Class inheritance, overriding mechanisms, subclassing, and multiple inheritance. |
| **`python-input_output`** | File reading, writing, parsing, and JSON standard serialization. |
| **`python-serialization`** | Advanced serialization mechanisms for Python objects. |
| **`python-test_driven_development`** | Writing robust unit tests in Python utilizing `Docstrings` and the `unittest` framework. |
| **`python-abc`** | Understanding and implementing Abstract Base Classes and interfaces in Python. |
| **`SQL_introduction`** | Basics of relational databases, introductory MySQL commands, Data Definition Language (DDL). |
| **`SQL_more_queries`** | Advanced database querying, privileges, Data Manipulation Language (DML), and complex `JOINS`. |
| **`python-object_relational_mapping`** | Connecting Python scripts to MySQL databases using `MySQLdb` and `SQLAlchemy` (ORM). |
| **`restful-api`** | Interacting with network requests, consuming and building RESTful APIs using standard HTTP protocol and JSON formats. |

---

## Environment & Requirements

All projects in this repository are designed to be tested and executed within a specific environment:

- **OS**: Ubuntu 20.04 LTS
- **Python**: Python 3.8.5 (Scripts must use `#!/usr/bin/python3` or `#!/usr/bin/env python3`)
- **Database**: MySQL 8.0 (for SQL and ORM tasks)
- **Style Guidelines**: Code must adhere to `pycodestyle` (version 2.8.*).
