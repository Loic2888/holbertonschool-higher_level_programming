# Python - Serialization

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)

## Description

This directory delves deeper into advanced data serialization techniques in Python. It explores alternative data formats such as Python's native `pickle`, `CSV`, `XML`, and custom serialization techniques beyond standard JSON.

## Files

| File | Description |
| :--- | :--- |
| `task_00_basic_serialization.py` | Basic serialization setup and dictionary serialization using standard methods. |
| `task_01_pickle.py` | Demonstrates object serialization and deserialization using the `pickle` module. |
| `task_02_csv.py` | Reading from and writing to Comma-Separated Values (CSV) formats. |
| `task_03_xml.py` | Serializing Python objects into Extensible Markup Language (XML) formats. |
