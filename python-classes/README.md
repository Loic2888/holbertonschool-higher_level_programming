# Python - Classes and Objects

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)

## Description

This directory introduces the basics of **Object-Oriented Programming (OOP)** in Python. It focuses on creating classes, defining private and public attributes, and instantiating objects. 

## Files

| File | Description |
| :--- | :--- |
| `0-square.py` | Defines an empty class `Square`. |
| `1-square.py` | Defines a class `Square` with a private instance attribute `size`. |
| `2-square.py` | Adds validation for the `size` attribute (must be an integer >= 0). |
| `3-square.py` | Adds a public instance method `area()` that returns the current square area. |
| `4-square.py` | Implements getters and setters for the `size` attribute using `@property`. |
| `5-square.py` | Adds a public instance method `my_print()` that prints the square using `#`. |
| `6-square.py` | Adds a private instance attribute `position` (tuple of 2 positive integers) and updates `my_print()`. |
