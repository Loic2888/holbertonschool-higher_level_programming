# Python - Data Structures: Lists, Tuples

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)

## Description

This directory focuses on core Python data structures: **Lists** and **Tuples**. It explores how to manipulate them, iterate through them, slice strings, and understand references and mutability.

## Files

| File | Description |
| :--- | :--- |
| `0-print_list_integer.py` | Prints all integers of a list, one per line. |
| `1-element_at.py` | Retrieves an element from a list at a specific index like in C. |
| `2-replace_in_list.py` | Replaces an element of a list at a specific index like in C. |
| `3-print_reversed_list_integer.py` | Prints all integers of a list, in reverse order. |
| `4-new_in_list.py` | Replaces an element in a list at a specific index without modifying the original list. |
| `5-no_c.py` | Removes all characters `c` and `C` from a string. |
| `6-print_matrix_integer.py` | Prints a matrix of integers. |
| `7-add_tuple.py` | Adds the first two elements of two tuples together. |
| `8-multiple_returns.py` | Returns a tuple with the length of a string and its first character. |
| `9-max_integer.py` | Finds the biggest integer of a list without using the built-in `max()` function. |
| `10-divisible_by_2.py` | Finds all multiples of 2 in a list and returns a new list of booleans. |
| `11-delete_at.py` | Deletes the item at a specific position in a list. |
| `12-switch.py` | Switches the integer values of `a` and `b`. |
