## Description

This directory explores how to interact with and build **RESTful APIs** using Python. It covers consuming external APIs with the `requests` library, serving HTTP with the built-in `http.server`, and building microservices using the `Flask` framework.

## Files

| File | Description |
| :--- | :--- |
| `task_02_requests.py` | Demonstrates how to fetch data from an external REST API using the `requests` package and parse JSON. |
| `task_03_http_server.py` | Sets up a basic HTTP server utilizing Python's native `http.server` module to respond to GET requests. |
| `task_04_flask.py` | Sets up a basic API using the `Flask` web framework, handling different endpoints and returning JSON. |
| `task_05_basic_security.py` | Enhances an API with basic authentication mechanism to secure the endpoints. |
